# Live2D AI/Chatbot 应用许可咨询模板

## 项目说明

- 项目性质：个人或学生比赛项目
- 应用形态：本地部署的 Web 数字人问答系统
- SDK：Live2D Cubism SDK for Web 5-r.4
- 角色资源：Live2D Original Characters
- 核心功能：LLM 对话、TTS 语音合成、音量驱动口型、模型切换和本地模型导入
- 发布方式：比赛现场演示；是否提供公开网址、安装包或源代码应按实际情况填写
- 商业情况：是否有奖金、赞助、商业孵化或企业参与应如实填写

## 中文咨询内容

您好，我们正在开发一个用于比赛展示的 AI 数字人问答系统。系统通过 Live2D Cubism SDK for Web 渲染 Live2D Original Characters，并根据外部 TTS 生成的声音驱动角色口型。

应用支持在本地发现、导入和切换多个 Live2D 模型。角色模型仅作为 AI 对话界面使用，我们不会将角色设计或模型制作声明为自主原创成果，也不会提供原始模型下载包。

烦请确认以下事项：

1. 该应用是否属于 Cubism SDK 所定义的 Expandable Application？
2. 个人或学生将其用于公开比赛演示时，是否需要签署 Publication License Agreement？
3. 如果提供公开 Web 演示地址、安装包或源代码，分别需要履行哪些许可手续？
4. 在应用中切换多个 Live2D Original Characters 是否需要额外申请？
5. 除官方版权声明外，是否还需要在应用界面或提交材料中增加其他标识？
